# GlobalTech AI ITSM – Dashboard Documentation
  # Dashboard Name
 # GlobalTech AI ITSM Dashboard

# Purpose
  . The dashboard provides centralized monitoring of AI Requests, AI Executions, AI Recommendations, AI Approvals, Audit Logs, and Agent activity.

# Platform
  ServiceNow Australia – Platform Analytics

# Dashboard Visualizations
  . Total AI Requests – Displays the total number of AI Requests.
  . AI Requests by Status – Shows requests grouped by their current status.
  . AI Executions by Status – Tracks queued, running, completed, failed, and waiting-for-approval executions.
  . AI Recommendations by Status – Tracks new, pending review, accepted, rejected, and applied recommendations.
  . AI Pending Approvals – Displays approvals awaiting a decision.
  . AI Audit Logs by Action Type – Summarizes AI audit activities.
  . AI Agent Execution Summary – Shows execution activity for each AI agent.
# Business Value
  . Provides visibility into AI operations.
  . Helps monitor execution outcomes.
  . Tracks recommendation and approval activity.
  . Supports governance and audit monitoring.
  . Helps identify failed or pending AI activities.
# Implementation Note
  The dashboard uses scripted AI-agent simulations and custom application tables. It does not currently connect to an external Large Language Model.
